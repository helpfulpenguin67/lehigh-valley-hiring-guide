# Lehigh Valley Hiring Guide

This folder is ready to publish with GitHub Pages.

## Publish it

1. Create a public GitHub repository named `lehigh-valley-hiring-guide`.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository's main branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.

GitHub will display the public site address after deployment finishes.

## Update it later

Replace `index.html` with the newer copy and commit the change. GitHub Pages will republish automatically.
